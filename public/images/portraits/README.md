# Images — /images/portraits

Portraits et images de la maison.

## Format recommandé
- **Format** : JPEG (qualité ~80) ou WebP. Le site convertit automatiquement en WebP/AVIF via next/image.
- **Ratio / dimensions** : Portrait 4:5 (ex. 1600×2000).
- **Poids** : ≤ 200 Ko par image, pour préserver les performances (Core Web Vitals).

## Bonnes pratiques
- Photographie naturelle, lumière douce, tons chauds cohérents avec la palette de la maison (ivoire, cuir, taupe).
- Éviter les visuels trop saturés, les arrière-plans chargés et les retouches agressives.
- Les fichiers actuels sont des placeholders : les remplacer en gardant les mêmes noms de fichiers, ou mettre à jour les chemins dans `content/creations.ts` et les pages concernées.
